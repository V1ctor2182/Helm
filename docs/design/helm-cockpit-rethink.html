设计理念 · 舰队台

它是什么

一面控制墙,一块监视器=一个真实的 Cursor+agent 窗口。状态实时来自 Claude Code 的 hook(刘海已在收)+ 每个项目的 loop-state(批次/绿门)。你不在这里写代码——你在这里扫一眼就知道谁在动、谁在等我,点一块跳过去。

为什么不是 Cursor

VSCursor 一个窗口只看得见自己那个项目。这一屏横跨你所有窗口所有项目——Cursor 结构上做不到跨窗口聚合,这正是它的盲区。

为什么不是 Claude Code Agent Teams

VSAgent Teams 只在一个项目内协调 agent、发桌面通知。它不知道你另一个 Cursor 窗口里买方项目的 loop 卡在 A1。舰队台跨项目,这是它的上一层。

代价 / 风险

要能真读到每个窗口的状态——依赖 hook 桥覆盖所有会话 + 能解析各项目的 loop-state 文件(你的 backlog/LOOP-STATE 格式)。窗口很多时,墙的密度和排序(「谁最该被我看」)是设计难点。

B收件箱 · Agent Inbox 赌注:路由 — 谁需要我,主动排队找上门

别让你去 alt-tab 找活——把所有窗口里「需要你拍板的事」汇成一条优先队列推给你: 权限请求(刘海 hook)、agent 的选择题、绿门待审(build/test 绿了等你合)、loop 卡住。 你像处理邮件一样一条条过——批准 / 回答 / 稍后,每个回答自动路由回对应的窗口和 agent。 这是 LangChain 那套 Agent Inbox,但架在你整支舰队之上,不是单个 agent。

设计理念 · 收件箱

它是什么

把「需要人的时刻」从各个窗口里抽出来,汇成一条按紧急度排好的队列送到你面前。你不再主动去找谁需要你,而是需要你的事主动来找你——像邮件收件箱,但收的是全舰队 agent 的求助。

为什么不是原生通知

VSClaude Code 的桌面通知只告诉你「某个 session 好了」,散、无优先级、点开还得找窗口。收件箱把它们聚合 + 排序 + 就地可操作——批准/回答直接在这里做,自动回到对应 agent。

直接落在 Helm 已有能力

刘海的 hook 桥已经在接 Claude Code 的权限请求(BridgeServer 那套)。收件箱就是把它从刘海的小卡片,升级成全屏、跨项目、带绿门/选择题/卡住的完整人在环队列。落地成本低。

代价 / 风险

只解决「谁需要我」,不给总览(要配 A 的墙做全局态)。排序策略是命门:排错了你还是得自己翻。绿门/选择题这些非权限事件,需要 loop 侧和 agent 侧主动上报,不只是 hook。

C总谱 · Conductor + 大脑 赌注:护城河 — 一个大脑喂所有项目,成果回一处

每个 Cursor 窗口的 agent 现在是孤儿:只看得见自己那个 repo,不认识你、不认识你别的项目。 Helm 的独家位置是——它横跨你所有项目 + 拥有你的个人大脑。总谱把你的约定/记忆/决策喂进每个项目的 agent (helm 用「cron 本地墙钟」那条决策、买方用「不编造数字」那条约束),再把每个项目的成果收回你一处的日记/记忆, 并总览每个项目的 loop 进度。Cursor / Devin / Agent Teams 都被锁在单项目里——只有 Helm 能同时看见你所有的活和你这个人。

设计理念 · 总谱

它是什么

驾驶舱作为你整套实践的总谱:你的约定/记忆/方法论从这里流进每个项目的 agent,每个项目的产出从这里收回你一处的日记和记忆,顺带总览每个项目的 loop 进度。它是把「你这个人」注入你所有活的那一层。

为什么只有 Helm 能做

VSCursor/Devin/Agent Teams 结构上都锁在单项目/单仓库。没有任何工具同时坐在你所有项目之上、又拥有你的个人大脑——因为它们没有你的记忆、日记、跨项目视野。这是抄不走的护城河。

复利效应

项目 A 沉淀的记忆,项目 B 直接命中、少走弯路。做的项目越多、用得越久,你的大脑越厚、每个 agent 越懂你。这是订阅制单项目工具给不了的个人复利。

代价 / 风险

最激进、最依赖 Helm 记忆/RAG/记录够强够准。喂错约定或命中噪音,会变成「大脑添乱」。它是语境层,要架在 A(总览)/B(路由)提供的实操界面之上,单独存在会太抽象。

建议:三层合一,但底座是「不替代 Cursor」

大前提变了:Helm 驾驶舱不碰编辑器、不抢 Cursor 的活。你继续在 N 个 Cursor 窗口里干活;Helm 只做你缺的那一层——控制塔。 三个方向是这层的三个面:A 舰队台=一屏看全所有窗口的 loop(解决「失去总览」)、 B 收件箱=谁需要我主动排队找上门(解决「alt-tab 当轮询器」)、 C 总谱=你的大脑喂所有项目、成果回一处(解决「凭什么只有 Helm」——护城河)。 「接管」不再是打开 Helm 里的编辑器,而是一键跳到那个 Cursor 窗口。刘海的「3 live」就是这套东西已经跑起来的证据。

A · 舰队台(骨架)

默认页。跨窗口跨项目的控制墙。回答「失去总览」。风险:读全窗口状态依赖 hook 覆盖 + loop-state 解析。

B · 收件箱(高频入口)

谁需要我 → 排队送来,就地处理回路由。直接接 Helm 已有的刘海 hook 桥,落地最快、日常最高频。

C · 总谱(护城河)

贯穿 A/B 的语境层。一个大脑喂所有项目、成果回一处。回答「凭什么只有 Helm」,别人结构上抄不走。
