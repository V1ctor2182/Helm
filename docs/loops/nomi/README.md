# NOMI 重塑 Loop 工作区(主工作台 · frontend/)

这是阶段 4「NOMI 全站重塑」loop 的**专属工作区**——loop 自己管这里,想记什么记什么。
约定的最小结构(可自行扩展,别把产物散落到仓库别处):

- `log.md` —— 每轮一条(时间/对齐块/门/取舍/commit),追加式
- `reports/` —— 每轮 report(round-NN.md);夜间模式早上从这里补看
- `shots/` —— 视觉对比截图(设计稿块 vs 实现,dark/light);大图可放 /tmp,关键留档放这
- `backlog.md` —— 本 loop 的复查发现(P0/P1/P2);全局项仍进 docs/design/helm-review-backlog.md
- 其他 loop 觉得需要的(parity 矩阵/块清单勾选表/…)自建自记

设计基线(只读):docs/design/helm-journal-pro.html + DESIGN.md NOMI 段。
铁律:功能不减/契约不破/设计稿只读/禁 emoji;硬门与流程见 docs/design/helm-loop-procedure.md 阶段 4。
